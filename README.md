## Overview

This project is a responsive Device Shop Checkout page, developed as a solution for a devChallenges challenge. The layout consists of two main sections: a summary of the products and a contact information form.

The page is designed to be fully responsive and adapt to different screen sizes.

### What I learned

* **Responsive Layouts with Bootstrap:** Effectively utilizing Bootstrap's grid system, utility classes, and media queries to create a layout that adapts seamlessly from mobile to desktop.
* **Form Styling and Structure:** Styling form elements for a clean, user-friendly interface and structuring the contact information form with various input types and a dropdown for country selection.
* **Fundamental CSS Techniques:** Implementing Flexbox for alignment and spacing within product cards and header, and generally improving CSS skills.

### Useful resources

* [Bootstrap 5 Documentation](https://getbootstrap.com/) - Essential for the responsive grid, components, and utility classes used in the project.
* [Font Awesome Icons](https://fontawesome.com/) - Used for the delete icon (`fa-solid fa-xmark`) in the product cards.

### Built with

## Features

This application/site was created as a submission to a [DevChallenges](https://devchallenges.io/challenges-dashboard) challenge.

Key features include:

* **Product Summary Section:** Lists three items (iPhone 17 Pro, Apple Watch, iMac) with quantity, color/details, and price.
* **Pricing Breakdown:** Displays Sub total, Tax, and Total cost.
* **Coupon Input:** An input field and button for applying a coupon code.
* **Contact Form Section:** Collects user information: First & Last name, Email Address, Country (dropdown), and Postal Code.
* **Responsive Design:** The layout changes from a single column on smaller screens to two columns (summary and form) on larger screens.
